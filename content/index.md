# foreword

These notes reflect my opinions on programming, this includes architecture, design and specific semantics of different philosophies and styles

All of these opinionated rambling notes are in `schizoid ramblings/`, but there is also some more structured and objective content in `basics/`

All notes are tagged with a a `topic difficulty` property, this outlines the experience level at which I think that topic becomes relevant, **not the level at which it should be explored**. I would recommend all skill levels to explore all of these topics

If you are interested in my takes on programming I would recommend starting from [[standardization]] and branching out from there

Otherwise you will probably want to start with [[your first program]]

This foreword doubles as a brief table of contents, if you want to jump to a specific topic or get to know what is discussed read on below.
